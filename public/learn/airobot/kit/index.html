วิธีเปิดหน้า AI Driver

เบราว์เซอร์ยอมให้ใช้พอร์ตและกล้องเฉพาะหน้าที่ปลอดภัย คือหน้าที่เปิดจาก https หรือจาก localhost

ทางที่ง่ายที่สุด เปิดจากหน้านี้เลย

หน้านี้อยู่บนเว็บที่ขึ้นต้นด้วย https กดปุ่ม เปิดหน้า AI Driver ข้างบนใน Chrome หรือ Edge ได้เลย ไม่ต้องใช้ python และไม่ต้องพิมพ์คำสั่งอะไร

อีกทาง เปิดจากไฟล์ในเครื่อง ผ่าน localhost (ผู้ใหญ่ทำ)

  1. ดาวน์โหลดไฟล์ zip แล้วแตกไฟล์ไว้ในโฟลเดอร์หนึ่ง
  2. เปิด Terminal (Mac หรือ Linux) หรือ Command Prompt (Windows) ในโฟลเดอร์ที่มีไฟล์ ai-driver.html
  3. พิมพ์คำสั่งนี้ (บน Windows ถ้าหาคำสั่ง python3 ไม่เจอ ลอง py -m http.server) 
    python3 -m http.server
  4. เปิด Chrome หรือ Edge ไปที่ http://localhost:8000/ai-driver.html
  5. เล่นเสร็จแล้ว กลับไปที่ Terminal แล้วกด Ctrl + C

ดับเบิลคลิกไฟล์ตรงๆ อาจใช้ได้ใน Chrome แต่ยังไม่ยืนยัน

ใช้ Chrome หรือ Microsoft Edge บนคอมพิวเตอร์ Windows Mac Linux หรือ ChromeOS ใช้ Safari ไอโฟน และไอแพดไม่ได้ Firefox รุ่นใหม่และ Chrome บน Android รุ่นใหม่รองรับแล้ว แต่ยังไม่ได้ทดสอบกับโครงงานนี้ จึงแนะนำให้ใช้คอมพิวเตอร์

⚠ ปลอดภัยไว้ก่อน
  • ทำกับผู้ใหญ่ทุกครั้ง
  • เล่นบนพื้นเท่านั้น ห้ามบนโต๊ะ
  • ใช้ความเร็วต่ำตามโค้ด
  • ผู้ใหญ่อยู่ใกล้สวิตช์ถ่านตลอดเวลา
  • ทดสอบล้อลอยก่อน
  • นิ้วห่างล้อ
  • ปิดถ่านก่อนถอดสาย
  • ไม่ทิ้งให้รถวิ่งโดยไม่มีคนดู
  • เรื่องถ่าน ห้ามใช้ถ่านเก่าปนใหม่ ห้ามลัดวงจร ถอดถ่านเมื่อเล่นเสร็จ
  • ใช้ท่ามือหรือการ์ด ไม่ใช้หน้าคน
  • ไม่ต่อแบบไร้สายในโครงงานแรก

AI Driver kit

This kit connects an image model that you train yourself in Teachable Machine to the robot car from lesson 16. The computer's webcam looks at an arrow card or a hand sign, the AI in the browser picks one letter (F, L, R or S) and sends it down the USB cable, and the Arduino turns the wheels. The AI is the brain, the car is the body, the cable is the nerve, and you watch the result and change your hand sign.

Full step-by-step guide in the lesson (level 9)

Honest note The web page was tested with a pretend robot and a pretend camera. It has not been tested with a real robot and a real camera. The Arduino code was logic-tested on a computer but has never been compiled for a board. Press Verify in the Arduino IDE before you use it.

Network and privacy (read with an adult first)
  • The AI Driver page loads two libraries from cdn.jsdelivr.net, TensorFlow.js 4.22.0 and @teachablemachine/image 0.8.5 (pinned versions), and loads your model from Google's servers.
  • Camera frames are processed in the browser. The AI Driver page does not upload them.
  • The link you get from "Upload my model" is public: anyone who has it can use the model. Train on arrow cards or hand signs only, never on faces.
  • Google says the example photos stay on your computer while you train, unless you choose to save the project to Google Drive.
  • This page you are reading has no scripts and sends nothing anywhere.

How to open AI Driver

Browsers only allow serial ports and the camera on secure pages: pages opened from https or from localhost.

Easiest: open it from this page

This page is served over https, so just press Open AI Driver above in Chrome or Edge. No Python and no commands needed.

Alternative: run it from your own computer via localhost (adult step)

  1. Download the zip and unzip it into a folder.
  2. Open Terminal (Mac or Linux) or Command Prompt (Windows) in the folder that contains ai-driver.html.
  3. Type this command (on Windows, if python3 is not found, try py -m http.server): 
    python3 -m http.server
  4. Open http://localhost:8000/ai-driver.html in Chrome or Edge.
  5. When you are done, go back to the terminal and press Ctrl + C.

Double-clicking the file may work in Chrome, but this is not confirmed.

Use Chrome or Microsoft Edge on a Windows, Mac, Linux or ChromeOS computer. Safari, iPhone and iPad do not work. Newer Firefox and newer Chrome on Android support Web Serial, but they have not been tested with this project, so please use a computer.

⚠ Safety first
  • Always build and drive with an adult.
  • Drive on the floor only, never on a table.
  • Keep the low speeds in the code.
  • An adult stays next to the battery switch the whole time.
  • Test with the wheels lifted first.
  • Keep fingers away from the wheels.
  • Switch the battery pack off before unplugging the USB cable.
  • Never leave the car running with nobody watching.
  • Batteries: never mix old and new, never short-circuit them, and take them out when you finish.
  • Use hand signs or cards, never faces.
  • No wireless connection in your first build.

The 12 steps in short

  1. Check the body first: upload the lesson 16 test code, put the car on a box with the wheels lifted, and check that both wheels turn forward.
  2. Make 4 cards: up arrow, left arrow, right arrow and an open palm.
  3. Teach the eyes in Teachable Machine: classes Forward, Left, Right, Stop and Nothing, at least 50 pictures each, cards or hands only.
  4. Train, then test in the preview: every sign should reach 80% reliably.
  5. Export, press Upload my model, and copy the link.
  6. Battery switch off: Verify, then Upload ai_driver_car.ino, then close the Serial Monitor.
  7. Open AI Driver in Chrome or Edge from https or localhost.
  8. Wheels still lifted: switch the battery on, press 1. Connect robot, pick the port, paste the link, press 2. Start camera.
  9. Run the 8 wheels-lifted safety tests. All must pass, including STOP, Esc and switching tabs (the wheels must stop).
  10. Drive on the floor only. Clear the area first, with no pets or small children nearby. An adult holds the cable loosely and stays next to the battery switch. Keep the speeds in the code, and press STOP or Esc at any time.
  11. Experiment, for example change THRESHOLD to 0.6 or 0.95. Editing the code needs your own copy: download the zip, edit ai-driver.html in a text editor, then open it through localhost (the alternative above). The page on this website cannot be edited.
  12. Pack up: press STOP, switch the battery off, then unplug the USB cable.
