Cyber 101

เส้นทางแฮกเกอร์สายขาว เข้าใจการโจมตีเพื่อป้องกันตัว

เรียนความมั่นคงปลอดภัยไซเบอร์ตั้งแต่ศูนย์จนถึงระดับลงสนาม CTF โดยยึดหลัก เข้าใจการโจมตีเพื่อป้องกันตัว ฝึกเฉพาะในแล็บของคุณเอง และรู้ขอบเขตทางกฎหมาย

⚠️ ก่อนเริ่ม อ่านให้ชัด

ทุกบทให้ฝึกกับระบบหรือแล็บที่เป็นของคุณเอง หรือที่ได้รับอนุญาตเป็นลายลักษณ์อักษรเท่านั้น การเข้าถึงหรือทดสอบระบบของผู้อื่นโดยไม่ได้รับอนุญาตผิดกฎหมายตาม พ.ร.บ.คอมพิวเตอร์ คอร์สนี้เน้นการป้องกัน ไม่ใช่การไปโจมตีใคร

บทที่ 0

รากฐานและจริยธรรม: แฮกเกอร์สายขาวคือใคร

ประเภทของแฮกเกอร์ กรอบจริยธรรม พ.ร.บ.คอมพิวเตอร์ไทย หลัก CIA และกฎเหล็กว่าฝึกได้เฉพาะระบบของตัวเอง

 บทที่ 1

พื้นฐานระบบ เครือข่าย และคอมมานด์ไลน์

ระบบปฏิบัติการ สิทธิไฟล์ พื้นฐานเครือข่าย IP พอร์ต DNS HTTP และการตั้งแล็บ VM ของตัวเองอย่างปลอดภัย

 บทที่ 2

เว็บทำงานอย่างไร มองจากสองฝั่ง

client/server, request/response, cookies, sessions, headers และการใช้ browser dev tools เพื่อเข้าใจการทำงานของเว็บ

 บทที่ 3

ช่องโหว่เว็บ 1: Injection และ XSS

เข้าใจ SQL injection และ Cross-site scripting ระดับแนวคิด สาธิตในเว็บฝึกของตัวเอง แล้วเรียนวิธีอุดช่องโหว่ให้ถูกต้อง

 บทที่ 4

ช่องโหว่เว็บ 2: Authentication และ Access Control

ปัญหา broken authentication, session management, IDOR/broken access control, security misconfiguration และวิธีป้องกันแต่ละอย่าง

 บทที่ 5

เครื่องมือสาย Security (ใช้ในแล็บของเรา)

รู้จัก Burp Suite, nmap, browser dev tools และการอ่านเขียน HTTP ด้วยมือ โดยใช้กับระบบของตัวเองหรือแล็บเท่านั้น

 บทที่ 6

เขียนโปรแกรมสาย Security ด้วย Python

เขียนสคริปต์เล็ก ๆ สายตรวจสอบและป้องกัน เช่น ตรวจความแข็งแรงรหัสผ่าน แฮชและตรวจสอบ อ่าน log และเข้าใจ hashing vs encryption

 บทที่ 7

การเข้ารหัสเบื้องต้น

เข้าใจ symmetric/asymmetric encryption, hashing, TLS, digital signatures และทำไมไม่ควรเขียน crypto เอง

 บทที่ 8

การป้องกันและ Hardening (Blue Team)

อ่าน log ตรวจจับความผิดปกติ incident response เบื้องต้น secure coding checklist การจัดการ secret และ dependency

 บทที่ 9

เส้นทางสู่ระดับโปร: CTF ใบรับรอง และอาชีพ

แพลตฟอร์มฝึกถูกกฎหมาย เส้นทาง bug bounty แบบ responsible disclosure ใบรับรองสายงาน และเส้นทางอาชีพด้านความปลอดภัย
คอร์สนี้จัดทำเพื่อการศึกษาด้านความมั่นคงปลอดภัยไซเบอร์เชิงป้องกัน (ethical security) ให้ฝึกเฉพาะกับระบบหรือแล็บที่เป็นของคุณเอง หรือที่ได้รับอนุญาตเป็นลายลักษณ์อักษรเท่านั้น การเข้าถึงหรือทดสอบระบบของผู้อื่นโดยไม่ได้รับอนุญาตผิดกฎหมาย เนื้อหาเป็นความรู้ทั่วไป ไม่ใช่คำแนะนำทางกฎหมาย · จัดทำโดย นพ. สหรัฐ อังศุมาศ ประสาทแพทย์ · สหวรรณคลินิก
